FAQ

Pertanyaan yang Sering Diajukan

Masih ragu? Ini jawaban untuk pertanyaan yang paling umum.

Berapa lama proses pembuatannya?

Landing page umumnya 3–5 hari, company profile atau toko online 1–2 minggu, sedangkan aplikasi/APK dan sistem custom bisa beberapa minggu tergantung fitur. Timeline pasti saya berikan di penawaran.

Apakah bisa dibuatkan aplikasi Android (APK)?

Bisa. Contohnya aplikasi kasir toko lengkap dengan scan barcode, stok, dan cetak nota lewat printer Bluetooth. Fitur lain disesuaikan kebutuhan usahamu lewat paket Pro / Custom.

Apakah harga sudah termasuk hosting & domain?

Setup hosting sudah termasuk di semua paket. Untuk nama domain (misalnya .com atau .id), biayanya mengikuti harga penyedia domain. Saya bantu pilihkan dan pasangkan.

Apakah saya bisa minta revisi?

Bisa. Revisi dibahas selama proses pengerjaan, dan ada garansi perbaikan bug selama 30 hari setelah serah terima.

Apakah website saya bisa di-update sendiri?

Bisa, sesuai paket. Untuk paket Bisnis dan Pro tersedia dashboard admin agar kamu bisa mengubah konten. Saya juga beri pengenalan singkat cara memakainya.

Bagaimana cara pembayarannya?

Pembayaran dibicarakan saat penawaran, biasanya dibagi dua tahap: uang muka di awal dan pelunasan setelah hasil sesuai kesepakatan. Untuk project besar bisa dibagi per tahap.

Saya orang awam, apakah tetap bisa?

Tentu. Kamu tidak perlu paham istilah teknis. Cukup ceritakan usahamu dengan bahasa sehari-hari, nanti saya bantu terjemahkan menjadi website atau aplikasi.
